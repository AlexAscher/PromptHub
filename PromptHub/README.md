# PromptHub — каталог AI-промптов

Веб-платформа для поиска, публикации и систематизации промптов для ChatGPT, Claude, Gemini, Midjourney и других нейросетей. Реализована по техническому заданию `PromptHub_TZ (2).pdf`.

## Быстрый старт

Нужен Docker (Docker Desktop, OrbStack или colima).

- **macOS:** дважды щёлкните `start.command`. Скрипт запустит Docker (если он выключен), соберёт контейнеры и откроет сайт в браузере.
- **Windows:** дважды щёлкните `start.bat` (внутри он запускает `start.ps1`). Нужен [Docker Desktop](https://www.docker.com/products/docker-desktop/) с WSL 2 — при установке оставьте галочку «Use WSL 2». Скрипт сам запустит Docker Desktop, если он выключен, проверит, что порт 8080 свободен, соберёт контейнеры и откроет сайт. Первый запуск требует интернета и занимает несколько минут. Другой порт: в командной строке `set PH_PORT=3000`, затем `start.bat`.
- **Вручную:**

  ```bash
  docker compose up -d --build
  ```

  Затем откройте http://localhost:8080

| Адрес | Назначение |
|---|---|
| http://localhost:8080 | Сайт |
| http://localhost:8080/_/ | Панель PocketBase (суперпользователь) |
| http://localhost:8025 | Mailpit — тестовый почтовый ящик (письма сброса пароля) |

Порт сайта можно поменять: `PH_PORT=3000 ./start.command`.

## Управление

```bash
docker compose down        # остановить
docker compose down -v     # остановить и удалить базу (при следующем запуске создастся заново с демо-данными)
docker compose logs -f     # логи
```

## Архитектура

```
docker-compose.yml
├── web        frontend/  Vue 3 + Vue Router + Bootstrap 5 (SPA, сборка Vite) → nginx
│                         nginx проксирует /api и /_/ на PocketBase
├── pocketbase backend/   PocketBase 0.40 — БД (SQLite), REST API, авторизация, файлы
│     pb_migrations/      схема коллекций, правила доступа, демо-данные, настройки SMTP
│     pb_hooks/           серверная логика: защита служебных полей, пересчёт рейтинга,
│                         счётчик просмотров, статистика (/api/ph/stats, /api/ph/authors)
└── mailpit               SMTP для писем восстановления пароля
```

### Коллекции (ТЗ, п. 4.3)

`users` (role, is_active), `categories`, `ai_models`, `prompts`, `ratings` (одна оценка 1–5 на пользователя), `reviews`, `selections` (подборки и «Избранное», приватные), `reports` (жалобы: спам / нерабочий промпт / оскорбительный контент).

### Реализованные функции

- **Гость:** главная (поиск, популярные категории, популярные/новые промпты), каталог с поиском по названию и содержанию, сортировкой (популярность, дата, рейтинг), фильтрами по категории и моделям ИИ, пагинацией; страница промпта с копированием; профили и список авторов; информационные страницы.
- **Пользователь:** регистрация с мгновенным входом, сброс пароля по email; публикация и редактирование промптов (лимиты 100/2000 символов, превью JPG/PNG до 2 МБ, теги); избранное и приватные подборки; оценки и отзывы с изменением и удалением; жалобы; личный кабинет (мои промпты, избранное, подборки, отзывы, жалобы, профиль с аватаром, смена пароля).
- **Администратор:** сводка, рассмотрение жалоб (удалить промпт / удалить и заблокировать автора / отклонить), управление промптами, отзывами, пользователями (блокировка, роли), категориями и моделями ИИ.
- Toast-уведомления, адаптивная вёрстка, светлая и тёмная темы.

Права доступа проверяются на сервере правилами коллекций PocketBase: редактировать промпт может только автор или администратор, подборки видит только владелец, заблокированный пользователь не может войти.

## Разработка фронтенда без Docker

```bash
docker compose up -d pocketbase mailpit
cd frontend && npm install && npm run dev   # http://localhost:5173, API проксируется на :8090
```
